# Nka Bulletin

Application de gestion de bulletins scolaires.

## Fonctionnalites
- Connexion via Google, Microsoft ou IMAP
- Verification biometrique et code PIN
- Consultation et fusion de bulletins PDF
- Notifications automatiques
- Mode sombre

## Development

```bash
flutter pub get
flutter run
```

## Build

```bash
flutter build apk --release
```
